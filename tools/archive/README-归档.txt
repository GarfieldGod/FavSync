FavSync 总库离线归档 —— 操作单
================================

一句话：按桶切（一桶 8 GiB，条目绝不跨桶）、7z 头加密、每期只打新增。
恢复时把所有桶解到**同一个库根**，目录不重叠 ⇒ 并集就是完整库，再点「扫描总库」认领。

一、打包（本机）
----------------
  set FAVSYNC_7Z_PASS=你的密码        （Git Bash: export FAVSYNC_7Z_PASS=...）
  python pack.py plan --root <库根目录> --out <出包目录> --batch 1 --bucket-gib 8
  python pack.py pack --root <库根目录> --out <出包目录> --batch 1 --volume-size 2g
  python pack.py verify --out <出包目录> --batch 1

  出包目录要有空间：一桶 8 GiB 峰值 ≈ 10 GiB（流式上传后即可删，见四）

二、上传（百度网盘客户端，不要用网页端：网页单文件上限 1 GB）
------------------------------------------------------------
  传 bkt-XXXX.7z.001/002/… 和同名 .sha256、MANIFEST-batchN.json
  单次批量上传上限 500 文件；每期约 120 卷，一次能传完

三、追加（后面新增的视频）
--------------------------
  库更新后重跑同样的 plan/pack，批次号 +1。已归档条目的 state.json 会自动跳过，
  桶号从上一期末尾续编，旧卷一个字节都不动。

四、上传完标记并释放本地空间
----------------------------
  python pack.py mark --out <出包目录> --batch 1 --prune
  （--prune 只在你想立刻腾空间时加；云端为准，sha256 已记在 MANIFEST 里）

五、恢复
--------
  1) 建一个空目录，把该期所有卷放进去（同一桶的卷必须齐）
  2) 7z x -p密码 -o<库根> bkt-0001.7z.001      （7-Zip 会自动按卷号接着读）
  3) 所有桶都解到同一个 <库根>，顺序无关
  4) 打开 FavSync → 库页 →「扫描总库」→ 自动认领入库
  5) python pack.py verify 只校验本地卷；恢复后可用 MANIFEST 里的 itemBytes 对账

六、必须记住
------------
* 密码丢了 = 全没。密码离线保存，绝不和包放同一个网盘目录。
* 桶内条目绝不跨卷组：一个 <avid>/c_<cid> 必须完整落在一个桶里（脚本已保证）。
* 百度网盘超 365 天不登录会把 2T 降成 100G（文件不删，但只读）—— 每年至少登录两次。
* 免费档下载慢：全量恢复一天到不了，按桶按需取；真要全量就临时开一个月会员。
