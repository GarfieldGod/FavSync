总库目录

备份文件放在这里。必须是本地固定盘：网络盘（UNC）和移动盘上 SQLite 的文件锁不可靠，会静默损坏账目。 改完需要重启服务才能生效（数据库路径在启动时定死）。

手机与 adb

FavSync 通过 adb 读手机缓存。程序自带的 tools\adb\adb.exe 会被自动使用， 只有想用别的版本时才需要填路径（留空 = 自动查找）。

服务端口

管理页地址是 http://127.0.0.1:端口。被别的程序占用时改成 8730 之类即可。

高级 展开

平时不用动：留空就按 PATH 和常见安装位置自动查找，下方「实际使用」显示的是真正生效的那个。

默认关闭：实测同一条流走本机代理只有 5 MB/s、直连 24 MB/s，B 站 CDN 在国内直连才是对的。 只有在必须代理出境时才打开。

冷备份与恢复

把总库的字节打成加密分桶（7z，连文件名一起加密），放到网盘或移动盘上，作为第三份副本。 桶坏了可以从库重打，所以它真正值钱的时刻是库也没了的时候。 桶大小决定的是恢复粒度：2 GiB ≈ 单桶下载 5.8 小时 @100KB/s，改动只影响之后新开的桶。

连接手机

方式一：手机开「设置 → 系统 → 开发者选项 → 无线调试」，连同一 Wi-Fi/同一 Tailscale 网段，输入页面上的 IP:端口（无线调试面板里显示的配对端口与连接端口不同，要用「IP 地址和端口」那行）。
方式二：USB 插上，允许调试授权，这里直接点连接即可自动识别。
